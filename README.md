# Faster Shredders
An Astroneer mod that makes Medium, Large, and Extra Large Shredders process items 5x faster. Scrap yield and power draw are unchanged.
Built for Astroneer 1.44.4. 

## Installation
Download here or from [Nexus Mods](https://www.nexusmods.com/astroneer/mods/232).
- **(RECOMMENDED)** Install with [Nexus Mods Vortex](https://www.nexusmods.com/vortex).
- Install with [AstroModLoader Classic](https://github.com/atenfyr/AstroModLoader-Classic).
- Manual installation by putting `000-FasterShredders-1.0.0_P.pak` into the game's `Astro/Content/Paks` folder.
